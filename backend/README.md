# GridMind Backend & ML Services

This directory contains the FastAPI server, schema definitions, and automated test suites for the GridMind system.

## Module Structure

- `app/main.py`: Application entrypoint.
- `app/api/`: REST API route controllers.
- `app/models/`: Domain models for hostel digital twin and loads.
- `app/schemas/`: Pydantic request and response contracts.
- `app/services/`: Forecasting and optimization orchestration services.
- `tests/`: Pytest unit and integration test suites.
